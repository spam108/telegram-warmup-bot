# Stage 1 Migration Plan: PostgreSQL Baseline

## Current State Summary
- **Database**: Основное хранилище переведено на PostgreSQL. `docker-compose.yml` поднимает сервис `postgres` с инициализацией схемы через `init.sql`, а приложение подключается по `DATABASE_URL`.
- **Python Dependencies**: Используется `asyncpg`; зависимость от `aiosqlite` удалена.
- **Docker Setup**: Сервисы `bot` и `postgres` запускаются совместно, данные хранятся в volume `postgres_data`.

## Цель этапа
Закрепить миграцию на PostgreSQL: убедиться в корректной конфигурации окружения, очистить артефакты SQLite и обновить документацию.

## Action Items

### 1. Проверка инфраструктуры
- Убедиться, что `docker-compose up` поднимает оба сервиса и бот подключается к PostgreSQL без ручных вмешательств.
- Настроить health-check или retry в приложении (при необходимости) для ожидания готовности базы.

### 2. Обновление зависимостей и образов
- Гарантировать наличие `asyncpg` во всех окружениях (docker, виртуальное окружение, CI).
- Исключить пакеты, связанные с SQLite, из `requirements` и скриптов развертывания.

### 3. Конфигурация и секреты
- Документировать переменные окружения `POSTGRES_PASSWORD`, `POSTGRES_USER`, `POSTGRES_DB` и формат `DATABASE_URL`.
- Обновить примеры `.env`, README и DEPLOYMENT-гайд.

### 4. Инициализация и миграции
- Поддерживать `init.sql` в актуальном состоянии, добавлять новые изменения через миграции либо обновления скрипта.
- Сохранить вспомогательные скрипты миграции с SQLite как исторический инструмент для переноса старых данных.

### 5. Тестирование
- Настроить тесты на использование временных PostgreSQL-баз (через фикстуры или testcontainers).
- Перепроверить сценарии резервного копирования (например, `pg_dump`).

## Acceptance Criteria
- Приложение и тесты запускаются только с PostgreSQL.
- Документация и скрипты развертывания не содержат ссылок на SQLite.
- Схема базы данных создаётся автоматически при первом запуске (через `init.sql` или `db.init_db`).
- Миграция с исторической SQLite-базы возможна посредством скрипта `scripts/migrate_sqlite_to_postgres.py`.
