# Быстрый старт Telegram Comment Bot

## Требования

- Python 3.10+
- PostgreSQL 12+
- Telegram Bot Token
- Telegram API credentials (API_ID, API_HASH)
- OpenAI API Key (для генерации комментариев)

## Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd telegram-warmup-bot-9-2
```

### 2. Быстрое развертывание

Используйте скрипт автоматического развертывания:

```bash
chmod +x quick_deploy.sh
./quick_deploy.sh
```

Скрипт автоматически:
- Создаст `.env` файл из шаблона
- Проверит наличие всех необходимых переменных
- Создаст виртуальное окружение
- Установит зависимости
- Инициализирует базу данных
- Создаст необходимые директории

### 3. Ручная настройка (альтернатива)

#### Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

#### Установка зависимостей

```bash
pip install -r requirements.txt
```

#### Настройка конфигурации

```bash
cp env.example .env
nano .env  # или используйте любой текстовый редактор
```

Заполните обязательные переменные:
- `BOT_TOKEN` - токен вашего Telegram бота
- `API_ID` - ID приложения Telegram
- `API_HASH` - хеш приложения Telegram
- `DATABASE_URL` - строка подключения к PostgreSQL
- `OPENAI_API_KEY` - ключ API OpenAI
- `PASSWORD` - пароль для доступа к боту

#### Инициализация базы данных

База данных инициализируется автоматически при первом запуске, но вы можете проверить подключение:

```python
python3 -c "
import asyncio
from db import init_db
asyncio.run(init_db())
print('Database connection OK')
"
```

## Запуск

### Простой запуск

```bash
python3 main.py
```

### Запуск через systemd (Linux)

```bash
sudo cp CDXBOT0310.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable CDXBOT0310
sudo systemctl start CDXBOT0310
```

Проверка статуса:
```bash
sudo systemctl status CDXBOT0310
```

Просмотр логов:
```bash
sudo journalctl -u CDXBOT0310 -f
```

### Запуск через Docker

```bash
docker-compose up -d
```

## Первое использование

1. Запустите бота
2. Найдите вашего бота в Telegram
3. Отправьте `/start`
4. Введите пароль из `.env` файла
5. Добавьте первый аккаунт через "Добавить аккаунт"
6. Настройте параметры аккаунта:
   - Вероятность комментирования (chance)
   - Системный промпт
   - Задержки между действиями
   - Настройки реакций
7. Запустите аккаунт

## Основные функции

### Комментирование
- Автоматическое комментирование постов в заданных каналах
- Настраиваемая вероятность комментирования
- Использование OpenAI для генерации комментариев

### Реакции
- Автоматические реакции на посты
- Реакции на комментарии в обсуждениях
- Настраиваемая вероятность и задержки

### Прогрев (Warmup)
- Автоматическое вступление в новые каналы
- Настраиваемое расписание
- Контроль количества вступлений в день

### Многоаккаунтность
- Поддержка неограниченного количества аккаунтов
- Независимые настройки для каждого аккаунта
- Автоматическое управление сессиями

## Мониторинг

### Логи
- Файл логов: `bot.log`
- Лог-канал Telegram: настраивается через `LOG_CHANNEL_ID`

### Статистика
- Используйте команду `/summary` в боте для просмотра статистики
- Или кнопку "📊 Общая статистика" в главном меню

## Устранение неполадок

### Бот не запускается
1. Проверьте наличие всех переменных в `.env`
2. Проверьте подключение к базе данных
3. Проверьте логи в `bot.log`

### Аккаунты не работают
1. Проверьте статус аккаунтов в боте
2. Убедитесь, что сессии аккаунтов валидны
3. Проверьте логи на наличие ошибок

### Проблемы с базой данных
1. Проверьте строку подключения `DATABASE_URL`
2. Убедитесь, что PostgreSQL запущен
3. Проверьте права доступа к базе данных
