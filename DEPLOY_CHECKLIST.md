# ✅ Чек-лист развертывания Telegram Comment Bot

## 🚀 Перед развертыванием

### Обязательные токены и ключи
- [ ] **BOT_TOKEN** получен от @BotFather
- [ ] **API_ID** и **API_HASH** получены от my.telegram.org
- [ ] **OPENAI_API_KEY** получен от platform.openai.com
- [ ] **PASSWORD** придуман (безопасный пароль для админ-доступа)

### Сервер готов
- [ ] **ОС**: Ubuntu 20.04+ / Debian 10+ / CentOS 8+
- [ ] **Память**: минимум 2GB RAM (рекомендуется 4GB+)
- [ ] **Диск**: минимум 10GB свободного места
- [ ] **Docker** установлен и работает

## 📋 Процесс развертывания

### Шаг 1: Подготовка проекта
- [ ] Создать директорию ~/telegram-comment-bot
- [ ] Скопировать файлы проекта через scp/rsync или SFTP (см. LOCAL_COPY.md)
- [ ] Директории sessions/ и logs/ созданы
- [ ] Скрипты имеют права выполнения

### Шаг 2: Конфигурация
- [ ] Файл .env создан и заполнен реальными значениями
- [ ] Все токены проверены на корректность
- [ ] Пароль админа установлен

### Шаг 3: Запуск через Docker
- [ ] `cd ~/telegram-comment-bot && ./docker-deploy.sh` выполнен
- [ ] Сервисы запустились без ошибок
- [ ] `sudo docker-compose ps` показывает статус "Up"

### Шаг 4: Верификация
- [ ] База данных доступна: `sudo docker-compose exec postgres psql -U postgres commentbot -c "\dt"`
- [ ] Логи бота не содержат критических ошибок
- [ ] Бот отвечает в Telegram

## 🔧 После развертывания

### Мониторинг настроен
- [ ] Логи проверяются регулярно: `sudo docker-compose logs -f`
- [ ] Статус системы мониторится: `sudo docker-compose ps`
- [ ] Резервное копирование настроено

### Безопасность обеспечена
- [ ] Firewall настроен (если используется ufw)
- [ ] Доступ к серверу ограничен
- [ ] Регулярные обновления системы

### Производительность оптимизирована
- [ ] Использование ресурсов мониторится: `sudo docker stats`
- [ ] При необходимости - увеличены лимиты в docker-compose.yml

## 🚨 Распространенные проблемы

### Если база данных не стартует
- [ ] Проверить логи: `sudo docker-compose logs postgres`
- [ ] Убедиться что порт 5432 свободен

### Если бот не отвечает
- [ ] Проверить токены в .env файле
- [ ] Посмотреть логи бота: `sudo docker-compose logs bot`
- [ ] Перезапустить бота: `sudo docker-compose restart bot`

### Если проблемы с памятью
- [ ] Увеличить память сервера
- [ ] Настроить лимиты в docker-compose.yml
- [ ] Очистить ненужные контейнеры: `sudo docker system prune`
