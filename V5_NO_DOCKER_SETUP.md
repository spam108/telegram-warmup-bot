# V5: Запуск бота без Docker

## Текущее состояние
✅ Работает:
- Запуск: `python3 main.py`
- Комментирование в каналах
- Реакции (эмодзи)
- Подключение к PostgreSQL
- Session файлы

🔧 Требует исправления:
- Сохранение настроек реакций из интерфейса бота

## Быстрый запуск
```bash
# 1. Остановить старые процессы
pkill -f "python3 main.py"

# 2. Перейти в директорию
cd /root/PGBOT1010

# 3. Переключиться на ветку V5
git checkout V5-no-docker

# 4. Запустить бота
python3 main.py
Настройка БД
bash
# Создать .pgpass для автоматической аутентификации
echo "localhost:5432:pgbot1010:postgres:postgres" > ~/.pgpass
chmod 600 ~/.pgpass
Проверка работы
Бот должен отвечать на /start

Аккаунты должны показывать статус

Комментарии и реакции должны работать
